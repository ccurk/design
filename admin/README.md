# 活动搭子 · 运营后台（admin/）

给运营同学用的网页后台：确认撮合、处理举报和待审内容、管理局、处理信用和申诉。

纯静态页面，**不需要构建**：Vue 3（仓库里的本地文件）+ 浏览器原生 ES module，由 `server/` 直接托管在 `/admin/`，接口在同源的 `/api/admin/*`。

## 怎么打开

1. 启动后端（第一次先装依赖、写演示数据）：

   ```bash
   cd server
   npm install
   npm run seed     # 清空数据库并写入演示数据；生产环境不要跑
   npm start        # 默认 http://localhost:3000
   ```

2. 浏览器打开 <http://localhost:3000/admin/>（打开 `http://localhost:3000/` 也会跳过来）。

后台页面和接口同源，不用另外配跨域或代理。页面用 hash 路由（`/admin/#/matching`），地址栏的路径永远是 `/admin/`，所以 `./app.js` 这类相对路径不会找错；从 `/admin/users` 这样的地址打开也会自动跳回 `/admin/#/users`。

## 登录

- 密码就是服务端的环境变量 `ADMIN_PASSWORD`；开发环境没设置时默认 `admin123`，生产环境必须设置。
- 同一个 IP 15 分钟内输错 10 次，会被锁到这 15 分钟结束。
- 登录后 token 存在浏览器的 localStorage（`dazi.admin.token`），7 天有效。任何接口返回 401（过期、被清掉）都会自动清掉 token 回到登录页，重新登录后回到原来那一页。
- 左侧菜单最下面是「退出登录」。

## 各页面做什么

### 概览 `#/dashboard`

- 今天的数字：今日新用户（和昨天比）、今日新意向、等你确认的局（点了去撮合池）、待处理举报和待审内容（点了去审核）、本周（近 7 天）履约率。
- 近 7 天成局数：柱状图，鼠标悬停或键盘聚焦柱子能看到具体数字；「表格」可以换成表格看同一组数据。
- 等你确认的局、待处理的举报、需要留意的事（申诉、受限的人、等了一天以上还没配上的人、近 7 天放鸽子次数）。
- 每 5 分钟自动刷新一次。

### 撮合池 `#/matching`

系统先配好，后台过目确认（规则见 `docs/api.md` 3.2）。

- **待确认**：每个方案的匹配度、成员（履约率、社交节奏、新人、信用一般）、为什么配到一起、风险提示。
  - **确认成局**：可以改标题、日期、开始时间、时长、地点、集合点、费用方式和预计每人费用、人数上限（不能少于已配的人数；多出来的名额系统会从池子里补邀）→ 给每个人发「撮合成功」，各自点「加入」才算数。
  - **调整成员**：把人移出（回到池子），或把池子里想做同一件事的人加进来，匹配度和风险会重新算。人数少于大家能接受的最少人数时不能确认。
  - **退回**：必须选一个原因，可以补充说明（只有后台能看到）；这些意向回到池子，同样这几个人同一天的同一件事不会再被配到一起。
- **已发邀请**：还在「邀请中」的撮合局：几个人加入了、谁还没回复、截止时间。
- **已退回**：退回过的方案和原因。
- **立即撮合一次**：马上跑一次撮合（平时每 5 分钟自动跑）。
- **自动成局**（默认关闭）：打开后，之后新配出的方案只要匹配度达到门槛（≥ 85 / 90 / 95）又没有任何风险提示，就直接成局。
- **还在等的人**：撮合池里的意向和等了多久，超过一天会标出来。

### 审核与举报 `#/moderation`

- **举报**：原因、类型、时间、匿名的举报人编号、被举报的内容、举报人补充和截图、被举报人的信用和被举报次数（能跳到「用户与信用」看信用记录）。
  处理方式五选一：驳回 / 警告 / 删除内容 / 限制 7 天 / 封号（封号要再确认一次），可以写备注。处理后举报人会收到结果通知。
  注意：选「警告」「限制 7 天」「封号」时，备注会作为提醒内容或原因发给被举报的人。
- **动态待审**：被内容审核拦下的动态（联系方式、广告等）。通过就发出来；不通过要选原因，作者会收到通知。
- **局待审**：用户发起的、命中内容审核的局。通过就发到广场；不通过要选原因，发起人会收到通知。

### 局管理 `#/events`

- 搜标题 / 地点，按状态（招募中、邀请中、已成局、待审核、已结束、已取消、未通过）和来源（撮合、用户发起、平台）筛选。表格太宽时在自己的框里横向滚动。
- 查看详情：时间和时长、地点和集合点、费用、成员和各自的状态、最近的群聊、AA 记账和被举报次数。
- **取消这个局**：要选原因，会通知所有成员，不扣任何人的信用；撮合局的意向放回撮合池。
- 待审核的局可以直接通过 / 不通过。
- **发起平台局**：直接发到广场，没有发起人，满员自动成群。

### 用户与信用 `#/users`

- **全部用户 / 受限中**：搜昵称或手机尾号，按信用等级（良好、一般、受限、已封号）筛选；表格里有履约率、到场、临时鸽、放鸽子、被举报次数。
- **用户详情**：信用数字、信用记录（会拉低履约率的记录可以撤销，履约率马上重算）、账号处理（限制 7 天 / 解除限制 / 封号 / 解封）。
- **申诉**：用户对某条信用记录的申诉。通过 = 撤销那条记录并通知 TA；驳回要写一句回复，会发给 TA。

## 文件

```
admin/
  index.html            页面入口
  app.js                入口：登录守卫、左侧菜单 + 内容布局、挂载
  style.css             样式（颜色、圆角、尺寸来自 design/admin/*.dc.html）
  favicon.svg
  src/
    api.js              api()：前缀 /api、JSON、Bearer token；失败抛出 { code, message }；401 回登录页
    router.js           hash 路由
    store.js            菜单上的待办角标
    format.js           北京时间格式化、各种状态的中文和配色
    ui.js               通用组件：菜单、提示条、标签页、开关、计数器、加载状态……
    pages/              六个页面：login、dashboard、matching、moderation、events、users
  vendor/
    vue.esm-browser.prod.js   Vue 3.5.13（带模板编译器），MIT 协议，见 vue.LICENSE.txt
  tools/
    e2e.mjs             端到端测试
```

- 不访问任何外部资源（没有 CDN、没有 Google Fonts），国内网络也能正常打开。字体：PingFang SC / Noto Sans SC / 微软雅黑 / 系统字体。
- 所有时间按北京时间（Asia/Shanghai）显示；表单里填的日期和时间也按北京时间理解。
- 用户写的内容一律当文本显示（不用 `v-html`）；用户上传的图片地址只放行 http(s) 和本站相对路径。
- 浏览器：近两年的 Chrome / Edge / Safari / Firefox（需要支持 ES module）。
- 手机宽度也能用：菜单折到页面上方，宽表格在自己的框里横向滚动。
- 升级 Vue：在一个临时目录里 `npm pack vue@<版本号>`，解压后把 `package/dist/vue.esm-browser.prod.js` 拷到 `vendor/`。

## 端到端测试

测试会改数据（确认 / 退回方案、处理举报、撤销信用记录……），请用一个临时数据库单独起一个服务，**每次跑之前重新 seed**：

```bash
cd server
DB_PATH=/tmp/admin-e2e.db node --no-warnings scripts/seed.js
DB_PATH=/tmp/admin-e2e.db PORT=3100 node --no-warnings src/index.js &

cd ..
node admin/tools/e2e.mjs                       # 默认 http://localhost:3100，密码 admin123
node admin/tools/e2e.mjs http://localhost:3100 admin123 --shots /tmp/admin-shots   # 顺便截图
```

- 需要 Playwright 和 Chromium（`require('playwright')` 能用就行）。
- 测试会用开发接口 `/api/auth/dev-login` 造两条待审动态和一个能被撮合的意向，所以服务端不能是 production 模式。
- 测试内容：登录（没填、输错、正确）；390px 手机宽度下每一页都不横向滚动；概览的数字和接口一致、柱状图和表格；撮合池（调整成员、确认成局、退回、立即撮合、自动成局开关）；审核（举报选警告、动态通过 / 不通过、局不通过）；局管理（筛选、详情、发起平台局、取消有人报名的局）；用户（搜索、撤销信用记录看履约率变化、限制 / 解除、申诉通过）；登录过期回到登录页；退出登录。全程不能有控制台报错和失败的请求。失败时退出码不为 0。
- 可选：`E2E_VUE_DEV=<Vue 开发版 vue.esm-browser.js 的路径>`，测试时换成 Vue 开发版，模板里写错的字段（`[Vue warn]`）也会算失败。

## 设计稿里暂时没做的

- 已发邀请里的「提醒还没回复的人」：后台还没有对应接口。
- 申诉里的「系统找到的证据」和申诉截图：接口没有这些数据。
- 举报详情里的「来自哪个局的群聊」：接口没有返回群聊消息所属的局。
- 确认成局 / 发起平台局里的自由文字「费用说明」：接口只有费用方式和预计费用，所以做成「费用方式 + 预计每人 ¥」。
- 概览里「比昨天」「比上周」：接口只有近 7 天每天的新用户数，所以只有「今日新用户」能和昨天比。
- 用户受限的原因：服务端没有保存，只能显示受限到什么时候。
